<h1>SpinLearn</h1>
SpinLearn is an interactive web application that helps users explore modern technology concepts through random topic generation. It provides clear explanations, real-world examples, advantages, limitations, a study timer, and progress tracking to make learning engaging and structured.

<h2>Demo:</h2> 

[https://spinlearn.vercel.app](https://spinlearn.vercel.app)

<h2>1. Features:</h2>

- Random Topic Generator
- Detailed Explanations with examples
- Browse Topics Mode
- Study Timer
- One Click Learning
- Learning Progress Tracker

<h2>2. Technologies Used:</h2>

- React.js
- Vite
- JavaScript
- CSS3
- React Icons

<h2>4. Installation:</h2>

- Clone the repository: git clone https://github.com/rosalyaa/SpinLearn.git
- Navigate to the project directory: cd SpinLearn
- Install dependencies: npm install
- Start the development server: npm run dev
- Open your web browser and visit: [https://spinlearn.vercel.app](https://spinlearn.vercel.app)




<h2>5. How It Works:</h2>
- The user selects the Tech category from the dropdown.
<br>
- Clicking Spin Topic randomly displays a technical concept.
<br>
- A built-in study timer helps users focus while learning.
<br>
- Clicking Explain reveals the topic’s explanation, example, advantages, and limitations.
<br>
- Users can mark topics as Learned, and the progress bar tracks completed topics.
<br>
- The Browse Topics section allows users to explore all available concepts without spinning.
